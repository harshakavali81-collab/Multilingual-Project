# Frontend

Responsive React + Vite UI for the multilingual knowledge base.

## Run locally
1. Ensure the backend is running at http://localhost:8000.
2. Install Node.js 22 or newer.
3. Run npm install from this directory.
4. Run npm run dev and open the Vite URL.

Set VITE_API_BASE_URL in .env.local to override the default API URL.

## Checks
Run npm run lint and npm run build before publishing. See the root README and docs directory for full setup, deployment, API reference, and feature workflow.
