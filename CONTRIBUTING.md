# Contributing

1. Create a branch for each focused change.
2. Keep secrets and local database files out of commits.
3. Add or update API tests when backend behavior changes.
4. Run the backend test suite before opening a pull request.
5. Run frontend lint and production build checks.
6. Update the README or documentation when endpoints, configuration, or behavior changes.
7. Evaluate representative Hindi, Telugu, Tamil, Kannada, and English examples before claiming cross-language semantic quality.
